# Carolina & Carmelo — Product & Engineering Studio

Static site prepared for GitHub Pages.

## Structure

- `index.html` — semantic page structure and inline SVG icon sprite
- `assets/css/styles.css` — complete visual system and responsive styles
- `assets/js/app.js` — language switcher, theme, service tabs, profile dialogs and animations
- `assets/images/` — profile photos, favicon and social preview

## Publish on GitHub Pages

1. Upload the contents of this folder to the root of the repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch (normally `main`) and the folder `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Optional metadata update

After the final GitHub Pages URL is known, add an absolute `canonical`, `og:url` and absolute `og:image` URL in `index.html` for the strongest social preview support.
